# HDF5 license information

HDF5 is distributed under a 3-clause BSD license, a copy of which can be found in
the [LICENSE file in the HDF5 GitHub repository](https://github.com/HDFGroup/hdf5/blob/develop/LICENSE).

After installing and loading the module, the license information can also be found in
`$EBROOTHDF5/share/licenses/HDF5` in the `COPYING` or `LICENSE` file depending on the
version of HDF5.
